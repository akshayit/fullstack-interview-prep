# Mock Interviews

## Fullstack Interview Loop

### Round 1: JavaScript and Frontend

- Explain event loop with promises.
- Build debounced search.
- Debug an Instagram feed rerender issue.
- Explain accessibility for checkout forms.

### Round 2: React and Next.js

- Explain reconciliation.
- Design state for Amazon checkout.
- Compare CSR, SSR, SSG, ISR.
- Debug stale product prices.

### Round 3: Backend and Database

- Design REST APIs for order tracking.
- Explain JWT vs sessions.
- Design indexes for order history.
- Debug high p99 latency.

### Round 4: System Design

- Design notification service.
- Design payment service.
- Design real-time tracking.
- Explain scaling, tradeoffs, monitoring, and security.

### Round 5: Behavioral and Leadership

- Tell me about a production incident.
- How do you mentor juniors?
- How do you handle disagreement with a tech lead?
- How do you prioritize tech debt vs features?

## HR Questions

2. Why are you looking for a change?
3. Why do you want this role?
4. What are your strengths?
5. What is one weakness you are improving?
6. What salary range are you expecting?

## Behavioral Questions

1. Tell me about a time you debugged a hard production issue.
2. Tell me about a time you improved performance.
3. Tell me about a time you disagreed with a teammate.
4. Tell me about a time you missed a deadline.
5. Tell me about a time you mentored someone.

## Resume Improvement Tips

- Start bullets with impact: "Reduced checkout API p95 latency from 900 ms to 220 ms."
- Mention scale: users, requests, data size, revenue, latency, uptime.
- Prefer product outcomes over task lists.
- Add technologies only if you can answer interview questions on them.
- Include links to GitHub, portfolio, deployed projects, and case studies.

## Salary Negotiation Tips

- Research market range before calls.
- Ask about full compensation: base, bonus, equity, benefits, remote policy.
- Avoid giving the first number when possible.
- Anchor with evidence: experience, competing offers, impact, and role scope.
- Stay polite and specific.
