# Online Compilers and Practice Links

Use these links when you want to quickly test interview code without setting up a local project.

## JavaScript, React, and TypeScript

- [OneCompiler React](https://onecompiler.com/react) - good for quick React component practice.
- [OneCompiler JavaScript](https://onecompiler.com/javascript) - good for JS snippets, arrays, strings, promises, and DSA.
- [TypeScript Playground](https://www.typescriptlang.org/play) - best for checking TypeScript types and compiler errors.

## SQL and MySQL Practice

- [Programiz SQL Online Compiler](https://www.programiz.com/sql/online-compiler) - good for SQL basics, joins, grouping, and constraints.
- [OneCompiler MySQL](https://onecompiler.com/mysql) - good for MySQL table/query practice.

## General Programming

- [Programiz C Online Compiler](https://www.programiz.com/c-programming/online-compiler) - useful if an interviewer allows C or asks language-agnostic DSA.

## How To Practice

1. Read the question.
2. Write the simplest working solution.
3. Add edge cases.
4. Explain time and space complexity.
5. Rewrite once without looking.
