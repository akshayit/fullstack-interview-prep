## Interview Rule

Do not only write code. Explain:

- What pattern you identified.
- Why brute force is too slow.
- What data structure removes repeated work.
- Complexity.
- Edge cases.

## Practical Interview Question Bank Style

| Pattern | Practical Explanation | Basic Example |
| --- | --- | --- |
| Array | Store ordered values and scan them efficiently. | Daily revenue list in seller dashboard. |
| HashMap | Remember previous values for fast lookup. | Find cart item by product ID. |
| Stack | Last item added is processed first. | Validate nested notification template brackets. |
| Queue | First item added is processed first. | Process order events in arrival order. |
| Binary Search | Cut sorted search space in half. | Find first bad deployment version. |
| Sliding Window | Track a moving range without recomputing. | Longest active session without duplicate event. |
| Graph | Model connected things. | Delivery zones connected by roads. |
| DP | Reuse answers to smaller repeated problems. | Count possible checkout paths. |
