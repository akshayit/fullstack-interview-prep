# Contributing

Thanks for improving this interview prep repository.

## Content Standard

Every topic should teach like a senior engineer mentoring a junior developer.

Include:

- Concept explanation.
- Beginner explanation.
- Realistic analogy.
- Interview answer.
- Production example.
- Code sample.
- Pitfalls.
- Debugging tips.
- Follow-up questions.
- Best practices.
- Performance concerns.
- Security concerns where applicable.

## Interview Question Format

Use this structure:

```md
## Question

What is the concept?

### Simple Explanation

Explain it in beginner-friendly English.

### Real-world Example

Use a product example like Instagram, WhatsApp, Amazon, Netflix, LinkedIn, Zomato, or a payment system.

### Code Example

Show practical code.

### Production Problem

Explain what breaks in real systems.

### Interview Follow-up

Add a deeper question the interviewer may ask.
```

## Pull Request Checklist

- [ ] The explanation is simple and practical.
- [ ] The example is realistic.
- [ ] Code is clean and runnable where possible.
- [ ] Tradeoffs are explained.
- [ ] Performance and security are covered where relevant.
- [ ] No generic textbook-only content.
